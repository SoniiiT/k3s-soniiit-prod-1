# Observability

## Surfaces

- Stack values and ingress routes: `kube-prometheus-stack/`
- Security telemetry: `Crowdsec/` and `Traefik/middleware/Crowdsec/`
- Dashboard links: `Homepage/homepage-values.yaml`

## Dependencies and invariants

- Prometheus, Grafana, Alertmanager, exporters, and kube-state-metrics are configured as one Helm stack in namespace `monitoring`.
- Route backend service names and ports are generated by the Helm release and must be checked after chart upgrades.
- CrowdSec middleware depends on the CrowdSec LAPI service and a bouncer credential.
- Monitoring ingress routes currently have TLS blocks commented out; do not assume HTTPS termination is active solely from the `websecure` entry point.

## Change and removal obligations

For stack changes, review generated service names, dashboards, rules, retention, resource limits, and route compatibility. For removal, remove ingress routes and Homepage links, then delete the Helm release and persistent data only with explicit approval.
